Backend Lambda & HTTP API Gateway

Trong phần này bạn xây dựng tầng xử lý chính cho toàn ứng dụng:

  • IAM Role tối thiểu quyền reloop2-api-lambda-role
  • Hàm Lambda Node.js 22 (ARM64) reloop2-api (512 MB, timeout 180 giây)
  • HTTP API Gateway (reloop2-api) tích hợp JWT Authorizer trỏ về Cognito, 7 route rõ ràng, CORS và giới hạn lưu lượng 20 req/s (burst 50) trên stage $default
  • Trigger Cognito Pre-SignUp gọi về reloop2-api để chặn đăng ký trùng email

Phần A — Tạo IAM Role tối thiểu quyền (reloop2-api-lambda-role)

  1. Vào IAM -> Roles -> Create role, chọn Trusted entity AWS service -> Lambda.

  1. Gắn AWSLambdaBasicExecutionRole (kèm Permissions Boundary nếu tài khoản nhóm yêu cầu).

  1. Đặt tên reloop2-api-lambda-role, gắn tags và bấm Create role.

  1. Mở reloop2-api-lambda-role -> Add permissions -> Create inline policy (reloop2-api-access) với phạm vi ARN chính xác cho DynamoDB, S3 listings/*, Bedrock (InvokeModel + ApplyGuardrail), Rekognition, tự gọi chính mình (SelfInvoke), Cognito ListUsers và Logs:

Phần B — Tạo Lambda Backend (reloop2-api)

  1. Vào AWS Lambda -> Create function:
    • Function name: reloop2-api
    • Runtime: Node.js 22.x, Architecture: arm64 (tối ưu hiệu năng/chi phí hơn x86_64)
    • Execution role: reloop2-api-lambda-role

  1. Tải lên gói zip backend reloop2-api.zip (index.js + index.js.map).

  1. Vào Configuration -> General configuration -> Edit: đặt Memory 512 MB, Timeout 3 min 0 sec (180s).

  1. Vào Configuration -> Environment variables -> Edit và điền đủ các biến môi trường:
BiếnGiá trị / Ý nghĩa
STAGEaws
AUTH_MODEcognito
TABLE_NAMEreloop2-core-table
IMAGE_BUCKETreloop2-images-7k3q
COGNITO_CLIENT_ID<Client ID của reloop2-web-client>
AI_MODEL_IDglobal.moonshotai.kimi-k3
ORIGIN_VERIFY_SECRET<chuỗi bí mật ngẫu nhiên 32 byte> (dùng chung với CloudFront ở Phần 5.8)
NODE_OPTIONS--enable-source-maps

Tuyệt đối bảo mật ORIGIN_VERIFY_SECRET, không đưa vào frontend hay Git. Backend kiểm tra header x-origin-verify bằng crypto.timingSafeEqual để chặn mọi truy cập đi vòng qua CloudFront gọi thẳng vào API Gateway.

Phần C — Tạo HTTP API Gateway (reloop2-api)

  1. Vào API Gateway -> Create API -> HTTP API -> Build, đặt tên reloop2-api và chọn integration tới Lambda reloop2-api.

  1. Tạo đầy đủ 7 routes (6 route công khai/auth/preflight và route tổng ANY /{proxy+} có bảo vệ JWT):
MethodRoute PathXác thực
POST/auth/sessionNone
POST/auth/logoutNone
POST/auth/refreshNone
GET/feed/publicNone
GET/feesNone
OPTIONS/{proxy+}None (CORS preflight)
ANY/{proxy+}JWT Authorizer (cognito)

  1. Giữ stage $default ở chế độ Auto-deploy, xem lại và bấm Create.

  1. Vào Authorization -> Create JWT authorizer:
    • Name: cognito
    • Identity source: $request.header.Authorization
    • Issuer URL: https://cognito-idp.ap-southeast-1.amazonaws.com/<User-Pool-ID>
    • Audience: <Client ID của reloop2-web-client> Rồi gắn cognito cho đúng route ANY /{proxy+}.

  1. Vào Develop -> CORS -> Configure, thêm http://localhost:5173, Allowed headers authorization, content-type, idempotency-key, Allowed methods *, Max age 3600 (Phần 5.8 sẽ thêm domain CloudFront).

  1. Vào Deploy -> Stages -> $default -> Throttling -> Edit: đặt Rate limit 20 req/s, Burst limit 50.

  1. Kiểm tra Integrations trên API Gateway và Resource-based policy trên Lambda để đảm bảo API Gateway có đủ quyền gọi Lambda theo từng route.

Phần D — Gắn Pre-SignUp Trigger trong Cognito

  1. Quay lại Cognito reloop2-user-pool -> Extensions -> Lambda triggers -> Add Lambda trigger, chọn Pre sign-up trigger -> reloop2-api để kiểm tra chống trùng lặp email trước khi tạo tài khoản.
