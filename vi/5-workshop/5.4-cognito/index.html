Xác thực Cognito & Đồng bộ Hồ sơ

Trong phần này bạn tạo Amazon Cognito User Pool (reloop2-user-pool), cấu hình 4 nhóm phân quyền RBAC (Admins, FinanceAdmins, Partners, Owners), thiết lập domain Managed Login v2 (reloop2-auth) và tạo Lambda Post-Confirmation (reloop2-post-confirmation, Python 3.12) để tự động ghi hồ sơ người dùng mới vào DynamoDB ngay sau khi xác nhận email.

Phần A — Tạo User Pool & Cấu hình Đăng nhập

  1. Mở Amazon Cognito -> User pools tại ap-southeast-1, bấm Create user pool.

  1. Trong bước Set up your application:
    • Chọn Single-page application (SPA)
    • Đặt tên App client là reloop2-web-client
    • Chọn Email làm định danh đăng nhập, yêu cầu các thuộc tính email và name khi đăng ký, sau đó bấm Create user directory.

  1. Khi pool khởi tạo xong, kiểm tra User Pool ID và bấm Go to overview.

  1. Ở trang Overview, bấm Rename, đổi tên thành reloop2-user-pool và lưu lại.

  1. Kiểm tra Authentication -> Authentication methods: bật Password, tắt MFA (No MFA) để luồng thử nghiệm gọn nhẹ (khi chạy thực tế có thể bật TOTP/SMS).

  1. Tại Authentication -> Sign-in: xác nhận đăng nhập bằng Email và không phân biệt hoa/thường.

  1. Tại Sign-up: xác nhận cho phép tự đăng ký, tự động xác minh qua email và bật Account recovery bằng Email (verified_email, ưu tiên 1).

  1. Gắn tags chuẩn workshop (Owner=team, Project=reloop2, Purpose=workshop) và xác nhận Deletion protection đang Active (ta sẽ chủ động tắt ở Phần 5.13 khi dọn dẹp).

Phần B — Tạo các Nhóm phân quyền (Groups)

  1. Vào User management -> Groups, tạo đủ 4 nhóm:
Tên nhómPrecedenceMô tả
Admins1Quản trị viên vận hành & duyệt hồ sơ
FinanceAdmins1Quản trị tài chính (duyệt STK, lệnh rút)
Partners2Cửa hàng sửa chữa & thu mua đã xác minh
Owners3Chủ thiết bị đăng tin bán/tái chế

Phần C — Cấu hình App Client & Domain Managed Login

  1. Mở Applications -> App clients -> reloop2-web-client: kiểm tra Authentication flows có ALLOW_USER_SRP_AUTH và ALLOW_REFRESH_TOKEN_AUTH, thời hạn Access/ID Token là 60 phút, Refresh Token là 5 ngày, bật Prevent user existence errors.

  1. Vào tab Login pages -> bấm Edit:
    • Tạm đặt Allowed callback URLs: http://localhost:5173/auth/callback
    • Tạm đặt Allowed sign-out URLs: http://localhost:5173/ (ở Phần 5.8 ta sẽ bổ sung URL CloudFront!)
    • OAuth 2.0 grant types: Authorization code grant (code)
    • Scopes: openid, email, phone

  1. Vào Branding -> Domain, thay domain mặc định bằng prefix reloop2-auth với Managed login version 2.

Phần D — Tạo IAM Role & Lambda Post-Confirmation (Python 3.12)

Ngay khi người dùng xác nhận mã OTP email, Cognito gọi đồng bộ Lambda reloop2-post-confirmation để ghi bản ghi hồ sơ Owner vào reloop2-core-table.

  1. Vào IAM -> Roles -> Create role, chọn Trusted entity là AWS service -> Lambda.

  1. Gắn policy quản lý AWSLambdaBasicExecutionRole (nếu tài khoản nhóm có Permissions Boundary như TeamAppRoleBoundary thì chọn thêm; tài khoản cá nhân để trống).

  1. Đặt Role name: reloop2-post-confirmation-role, gắn tag và tạo Role.

  1. Mở reloop2-post-confirmation-role -> Add permissions -> Create inline policy (JSON) để cấp đúng quyền dynamodb:PutItem trên bảng reloop2-core-table:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PutUserProfile",
      "Effect": "Allow",
      "Action": "dynamodb:PutItem",
      "Resource": "arn:aws:dynamodb:ap-southeast-1:123456789012:table/reloop2-core-table"
    }
  ]
}

  1. Đặt tên inline policy là DynamoDBWriteAccess và lưu lại.

  1. Chuyển sang AWS Lambda -> Create function:
    • Function name: reloop2-post-confirmation
    • Runtime: Python 3.12, Architecture: x86_64
    • Execution role: Chọn Role vừa tạo reloop2-post-confirmation-role

  1. Tải lên file zip mã nguồn lambda_function.py (reloop2-post-confirmation.zip với ConditionExpression="attribute_not_exists(PK)" chống ghi đè trùng lặp):
import datetime
import os
import boto3

dynamodb = boto3.client("dynamodb")
TABLE_NAME = os.environ["TABLE_NAME"]

def lambda_handler(event, context):
    if event.get("triggerSource") != "PostConfirmation_ConfirmSignUp":
        return event

    attrs = event["request"]["userAttributes"]
    user_id = attrs["sub"]
    email = attrs.get("email", "")
    name = attrs.get("name", "Unknown")
    role = "Owner"
    timestamp = datetime.datetime.utcnow().isoformat() + "Z"

    try:
        dynamodb.put_item(
            TableName=TABLE_NAME,
            Item={
                "PK": {"S": f"USER#{user_id}"},
                "SK": {"S": "PROFILE"},
                "GSI1PK": {"S": f"ROLE#{role}"},
                "GSI1SK": {"S": f"USER#{user_id}"},
                "email": {"S": email},
                "fullName": {"S": name},
                "role": {"S": role},
                "status": {"S": "ACTIVE"},
                "createdAt": {"S": timestamp},
            },
            ConditionExpression="attribute_not_exists(PK)",
        )
    except Exception as exc:
        print(f"Failed to write user to DynamoDB: {exc}")

    return event

  1. Kiểm tra General configuration (128 MB, timeout 3 giây) và thêm biến môi trường Environment variables: TABLE_NAME = reloop2-core-table.

Phần E — Gắn Trigger Post-Confirmation vào Cognito

  1. Quay lại reloop2-user-pool -> Extensions -> Lambda triggers, bấm Add Lambda trigger.

  1. Chọn Sign-up -> Post confirmation trigger, chọn hàm reloop2-post-confirmation và bấm Add Lambda trigger.
